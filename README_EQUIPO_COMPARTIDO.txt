Inventario de Máquinas · rediseño integral

Modelo de usuarios:
- Administrador General: control global.
- Supervisor: puede haber varios; el rol Supervisor se solicita al registrarse y requiere aprobación del Administrador General.
- Técnico: responsable técnico de una zona.
- Operador: responsable operativo de una zona.
- Cada zona tiene un Técnico y un Operador.

Catálogo:
- Pelucheras
- Wawa
- Wawa Doble
- Llaveros
- Solo Cutter
- Toy Soldier I
- Toy Soldier II
- Crazy Toy 3
- Otros modelos agregados mediante +.

Visitas de máquinas:
- Máquinas visitadas / máquinas sin visitar.
- Cada visita queda como historial independiente.
- Relojes COIN, WIN y MP: anterior, actual y diferencia automática.
- Placa: programación registrada.
- Pelucheras: peluches en máquina, depósito y cantidad anterior, con control contra WIN.
- Porcentaje de trabajo de la visita.
- Observaciones y repuestos utilizados.

Control de stock:
- Herramientas
- Elementos de limpieza
- Repuestos de fábrica
- Repuestos generales
- Stock mínimo y lista de reposición mediante estado de compra.
- Flujo de viaje: stock inicial/actual, tomado, usado y devuelto.
- Billetero separado en modelo físico (BV20, BV30, JIX ARES, Genius) y configuración numérica.
- Configuraciones iniciales: 1-2-6-36, 1-2-10, 1-10-14.

Repuestos de fábrica cargados:
- Hip Hop Elf
- Toy Soldier II
- Crazy Toy 3

Se conserva el historial de observaciones, mantenimientos y movimientos. El respaldo completo NO se importa automáticamente con esta versión; primero debe probarse la nueva estructura y luego realizar una importación controlada.
